# Archive

A finished plan or document is deleted by default. Git keeps it, and a current document describes the result.

A document is archived here only if all three of these are true:

1. **It holds knowledge that is nowhere else.** Examples are an investigation, a measurement, a rejected approach and why it failed, or research on external systems. If the knowledge belongs in a current document, move it there and delete the original.
2. **A concrete future situation will need it.** You can name that situation, for example "when someone proposes replacing pdf.js" or "when the PDF hit rate is measured again". "It might be useful someday" does not count.
3. **It is still true.** Facts about the outside world, or about a decision, that have not gone stale.

Every archived document starts with these two lines:

```
Kept because: <the knowledge it holds that exists nowhere else>
Needed when: <the concrete situation that will need it>
```

When you open an archived document and it no longer meets all three conditions, delete it.
